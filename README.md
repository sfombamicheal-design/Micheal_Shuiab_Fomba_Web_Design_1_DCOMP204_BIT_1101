StudentStay – Student Accommodation Website

Project Description

StudentStay is a student accommodation website designed to help students find affordable, safe and comfortable places to stay near their schools and universities in Freetown, Sierra Leone.

Objectives

- Help students find accommodation easily.
- Provide information about available student hostels and residences.
- Make accommodation searching easier and faster.
- Help students compare different accommodation options.

Website Pages

1. Home – Introduces the StudentStay website.
2. Accommodation – Displays available student accommodation.
3. About – Provides information about StudentStay.
4. Contact – Provides contact information.

Technologies Used

- HTML5 – For website structure.
- CSS3 – For website styling and layout.
